# Direção de produção

- Usar Remotion como framework do vídeo.
- Animar os SVGs com GSAP, integrado por `@remotion/gsap` e sincronizado aos frames do Remotion.
- Criar imagens e ícones com fundo transparente para composição em camadas.
- Definir as cenas com base na narração fornecida.
- Salvar código e recursos visuais no GitHub.
- Preferir processamento remoto; usar o notebook somente quando as alternativas remotas estiverem esgotadas.

## Áudio

O áudio original não faz parte dos arquivos públicos deste projeto. A referência para montagem será configurada separadamente.
